AgentBuyNetwork

Independent Indexes for AI Shopping Agents

AI agents that shop need to know which sellers they can actually read and work with. AgentBuyNetwork is a growing set of independent indexes, one per category, that list sellers and data sources publishing machine-readable resources: llms.txt files, public API documentation, and agent tools such as MCP servers.

Each index saves an agent, or the person building it, the step of finding and checking these sources one by one. We are early, and we are adding categories and sources as we go.

Live Indexes

  • AgentBuyParts.com auto, powersports, RV, marine, aviation, and equipment parts · 15 sources
  • AgentBuyGift.com gift retailers, gifting platforms, gift card APIs · 13 sources
  • AgentBuyBeer.com beer data, breweries, wine and alcohol · 7 sources
  • AgentBuyCoffee.com coffee roasters and ordering · 3 sources
  • AgentBuyGold.com gold price data · 2 sources
  • AgentBuySilver.com silver price data · 2 sources
  • AgentBuyPhone.com phones and refurbished devices · 1 source

Every index publishes /llms.txt and /llms-full.txt for agents to read directly.

How We List Sources

  • A source is listed only if it publicly offers an llms.txt file, public API documentation, or an agent tool, and we found it reachable on the date shown.
  • Descriptions summarize what each company says about itself. We do not rate, rank, or verify products, prices, or service quality.
  • Listings are free. We have no affiliation, partnership, or paid relationship with any company listed.
  • Each index shows the date it was last checked, plus a "Not Yet Listed" section for well-known sellers without public machine-readable resources.
